**Власник:** Denys Kuzin  

**Рік:** 2026  

**Версія документації:** 0.6.0 (мітка в шапці сайту та `mkdocs.yml` / `extra.doc_version`).

## Пакети для зовнішніх стейкхолдерів

Якщо експортуєш **підмножину** сайту для зовнішніх стейкхолдерів, використовуй сторінки розділу **Adoption** та **Executive brief**, а **прибери або узагальни** внутрішні hostname, ключі та операторські runbooks. Умови поширення нижче лишаються чинними, якщо їх не замінив окремий договір.

## Статус

Матеріали в `tools/linear-agent/docs/` і зібраний MkDocs-сайт охороняються **авторським правом** (Denys Kuzin), якщо **окрема ліцензія на шлях** (наприклад Apache 2.0 для опублікованого зрізу **Ship**) явно не передбачає іншого. Кореневий `LICENSE` **не** означає «усе тут Apache» — див. **Ship проти решти монорепо** нижче.

## Дозволено

- Внутрішнє використання в організації власника для розробки, експлуатації та онбордингу.  
- Внутрішні PDF/друк для співробітників і погоджених підрядників.

## Заборонено без письмового дозволу власника

- Публічне поширення повних копій поза організацією.  
- Комерційне використання документації як окремого продукту.  
- Приховування або видалення позначок про авторство.

Короткі цитати — з **атрибуцією** (автор + джерело).

## Ship проти решти монорепо

**Ship** (цей мануал у `tools/linear-agent/docs/` плюс автоматизація в `tools/linear-agent/`, яку ми публікуємо для фреймворку) — це частина, яку задумано ліцензувати **пермісивно** (наприклад Apache 2.0), коли її випускають окремо. **Решта** **ElMundiUA/elmundi** — зокрема код продукту й вебсайту — може залишатися **власницькою** або під **іншими** ліцензіями. Доки, код і активи — **не** один режим для всього репо: дотримуйся позначок на **конкретному шляху**, який копіюєш, або погодь письмовий дозвіл.
