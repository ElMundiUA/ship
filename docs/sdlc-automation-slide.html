SDLC automation (current)

Workflow linear-agent-sdlc-scheduled.yml runs on four separate crons (even UTC hours). Each scheduled trigger starts one workflow run with one job (Intake, Clarification, BA, or Developer). The Cursor Cloud Agent step runs only when the pick script returns an issue.

Intake / clarification / BA: status Todo, project ElMundi pre-release; intake = no stage:intake / needs:clarification / ready:developer. Backlog is manual-only. Developer: Todo + ready:developer + same project; otherwise the pick is empty. File: tools/linear-agent/docs/sdlc-automation-slide.html
