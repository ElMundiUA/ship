# Linear API key

**What it is.** A token that lets Ship read and write tickets in your Linear workspace.

**Where to get it.** Sign in at `linear.app`. Go to Settings → API (or look for "API" in the left sidebar). Click "Personal API keys" or create a new key if the option exists. Name it "Ship", copy the value, and save it — Linear shows the full token only once.

**Where it goes in Ship.** Onboarding wizard, "Workspace tracker" step → Linear section → API key field. You can also add it later in Settings → Integrations → Linear.

**Safety.** Linear API keys do not expire by default but can be revoked from the same settings screen. Revoking a key instantly blocks all API calls that use it.
