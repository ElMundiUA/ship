# Governance та RACI

**Призначення:** хто **власник політики** vs хто **оперує** автоматизацією.  
**Аудиторія:** менеджери інженерії, платформа, безпека.

Підлаштуйте ролі під свої назви; це **шаблон**.

| Активність | Product / EM | Platform / DevOps | Security | Розробники |
|------------|--------------|-------------------|----------|------------|
| **Пріоритизація Backlog** | A / R | C | I | C |
| **Промоут у Todo / мітки** | A | C | I | R |
| **Вміст промптів і skills** | A | R | C | C |
| **Секрети та env GitHub** | I | A / R | C | I |
| **Merge / реліз** | A | I | I | R |
| **Тріаж аудит-файндінгів** | A | C | R | I |
| **Токен і політика Snyk** | I | C | A / R | I |

**Легенда:** **R** — виконує, **A** — підзвітний, **C** — консультує, **I** — інформований.
